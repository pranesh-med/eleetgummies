# FLEET - Recovery Gummies for Athletes

A modern, high-performance website for FLEET recovery gummies engineered for student athletes.

## Features

- **Responsive Design**: Built with mobile-first approach
- **Modern Styling**: Gradient backgrounds, smooth animations
- **Multiple Pages**:
  - Home (Hero with features)
  - Shop (Best sellers)
  - Reviews (Customer testimonials)
  - Science (Product information)

## Colors & Branding

- Primary Pink: `#ff1493`
- Primary Green: `#00ff00`
- Primary Cyan: `#00d4ff`
- Primary Orange: `#ff8c00`
- Dark Background: `#0a0e27`

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Navigate through the pages using the navigation menu

## File Structure

```
.
├── index.html      # Home page
├── shop.html       # Shop/Products page
├── reviews.html    # Customer reviews
├── science.html    # Product science
├── css/

└── README.md       # This file
```

## Technologies Used

- HTML5
- CSS3 (with custom properties/variables)
- Responsive Grid & Flexbox
- CSS Animations

## Customization

Edit `css/styles.css` to customize:
- Colors
- Fonts
- Spacing
- Animations

## Deployment

To deploy this website:

1. **GitHub Pages**: Push to GitHub and enable Pages in settings
2. **Netlify**: Connect your GitHub repo and deploy
3. **Vercel**: Import your repository and deploy
4. **Custom Domain**: Configure your domain registrar to point to your hosting provider
